# Security Policy

## Supported Versions

Security fixes are only planned for the current `1.20.1` line of this repository.

## Reporting A Vulnerability

- Do not open a public issue for an undisclosed security problem.
- Use GitHub's private vulnerability reporting features when available.
- If private reporting is not available, contact the maintainers privately through GitHub.

Please include affected versions, reproduction details, and any proof-of-concept material needed to verify the report.
