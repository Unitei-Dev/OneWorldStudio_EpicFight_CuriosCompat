# Code of Conduct

## Our Pledge

We want this project to be a welcoming and respectful space for everyone participating in issues, pull requests, code review, and community discussions.

## Expected Behavior

- Be respectful and constructive.
- Focus on technical feedback and project goals.
- Accept good-faith criticism and course correction.
- Help keep discussions accessible, patient, and on-topic.

## Unacceptable Behavior

- Harassment, threats, or personal attacks
- Discriminatory language or exclusionary behavior
- Trolling, baiting, or repeated bad-faith arguments
- Sharing private information without permission
- Any conduct that would make collaboration unsafe or hostile

## Scope

This code of conduct applies to repository spaces, issue threads, pull requests, code review, and any other project-managed communication channels.

## Enforcement

Project maintainers may edit, remove, or moderate comments, issues, pull requests, and other contributions that violate this code of conduct.

## Reporting

Report incidents privately through GitHub when possible. Maintainers will review reports and respond with reasonable confidentiality and care.
